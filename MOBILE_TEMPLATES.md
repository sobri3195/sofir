# SOFIR Mobile Elementor Templates

## Overview

Complete collection of 20 mobile-first Elementor templates inspired by modern design systems like **Arcade** and **Swipe Pages**. These templates feature bold gradients, clean typography, and conversion-focused layouts optimized for mobile devices.

## Design Inspiration

### Arcade Style
- Clean, minimalist interface
- Bold gradient backgrounds (purple, blue, pink)
- Modern typography with heavy font weights
- Interactive elements with smooth animations
- Generous white space
- Mobile-first approach

### Swipe Pages Style
- Card-based layouts
- Bold, colorful gradients
- Strong visual hierarchy
- Conversion-focused design
- Smooth transitions
- Large, readable text

## Usage Guidelines

### Mobile-First Approach
1. **Optimize for Touch**: Minimum 44px touch targets
2. **Readable Text**: Minimum 16px body text
3. **Generous Spacing**: 20-40px section padding
4. **Bold Typography**: 700-900 font weights
5. **High Contrast**: Dark text on light, light on dark

### Performance
1. **Optimized Gradients**: CSS gradients (no images)
2. **Minimal Assets**: Text and icon-based
3. **Lazy Loading**: Load images on demand
4. **Small File Sizes**: JSON-based templates

### Accessibility
1. **Color Contrast**: WCAG AA compliant
2. **Font Sizes**: Large, readable text
3. **Touch Targets**: 44px minimum
4. **Clear Hierarchy**: Bold headings, clear sections

## Import Instructions

1. Open Elementor editor
2. Click "SOFIR Templates" button (folder icon)
3. Browse by category: Slider, Card, Page, Single, Archive
4. Search by tags: mobile, arcade, gradient, swipe
5. Preview template with full-screen modal
6. Click "Insert" to add to page
