## New Modules

### Restaurant Module
- Complete ordering system for dine-in and delivery
- Menu management with pricing and categories
- Order status workflow (pending → preparing → ready → completed)
- Customer information tracking (name, phone, address, table)
- REST API endpoints for orders and menu
- AJAX form submission
- Shortcodes: [sofir_restaurant_menu], [sofir_order_form]
- Event hooks: sofir/restaurant/order_created, sofir/restaurant/order_status_changed

### E-Course Module
- Complete learning management system
- Course catalog with pricing and levels
- Student enrollment system
- Progress tracking per user per course
- Lesson completion tracking
- REST API for enrollment and progress
- Shortcodes: [sofir_course_list], [sofir_course_progress], [sofir_my_courses]
- Event hooks: sofir/ecourse/enrolled, sofir/ecourse/lesson_completed
