# Generator Artikel SEO AI - Dokumentasi

## Ringkasan

Generator Artikel SEO AI adalah fitur canggih di SOFIR yang menggunakan Google Gemini AI untuk membuat artikel komprehensif dan dioptimalkan SEO secara otomatis. Fitur ini membantu pembuat konten menghasilkan artikel berkualitas tinggi dengan struktur, kata kunci, dan optimasi SEO yang tepat.

## Fitur-fitur

### 🤖 Pembuatan Artikel Bertenaga AI

Buat artikel lengkap dengan:
- **Konten dioptimalkan SEO** - Terstruktur dengan baik dengan kata kunci
- **Beberapa bagian konten** - Pendahuluan, isi, kesimpulan, FAQ
- **Struktur heading** - Hierarki H2, H3, H4 otomatis
- **Meta data** - Meta title dan description otomatis
- **Optimasi kata kunci** - Penempatan kata kunci natural
- **Saran tautan internal** - Rekomendasi posting terkait
- **Schema markup** - Data terstruktur JSON-LD

### 🎯 Opsi Kustomisasi

1. **Pengaturan Artikel:**
   - Judul Artikel - Topik atau judul utama
   - Kata Kunci Target - Kata kunci SEO utama
   - Tujuan Artikel - Informatif, edukatif, transaksional, review, panduan, daftar
   - Tone - Profesional, kasual, ramah, otoritatif, percakapan, teknis
   - Jumlah Kata - 300-5000 kata
   
2. **Gaya Penulisan:**
   - Sudut Pandang - Orang pertama, kedua, ketiga
   - Level Keterbacaan - Pemula, menengah, lanjutan
   - Level Kreativitas - Slider yang dapat disesuaikan (0.0 - 1.0)
   
3. **Opsi Konten:**
   - Sertakan Bagian FAQ - Checkbox
   - Sertakan Daftar Isi - Checkbox

### 📊 Analisis SEO

Generator menyediakan penilaian SEO komprehensif:

- **Skor SEO Real-time** (0-100)
- **Checklist SEO:**
  - Panjang judul (30-70 karakter)
  - Kata kunci di judul
  - Panjang meta description (120-160 karakter)
  - Kata kunci di meta description
  - Panjang konten (800+ kata direkomendasikan)
  - Kepadatan kata kunci (0.5-2.5% optimal)
  - Struktur heading (2+ H2 heading)
  - Kehadiran bagian FAQ
  - Kehadiran pendahuluan & kesimpulan

### 🔍 Tool Riset Kata Kunci

Fitur riset kata kunci built-in menyediakan:

- **Variasi Kata Kunci** - Saran kata kunci alternatif dengan kesulitan dan volume
- **Long-Tail Keywords** - Frasa kata kunci spesifik dan tertarget
- **Kata Kunci Terkait** - Istilah yang terkait secara semantik
- **LSI Keywords** - Kata kunci Latent Semantic Indexing
- **Kata Kunci Kompetitor** - Kata kunci yang digunakan kompetitor
- **Question Keywords** - Pertanyaan umum tentang topik
- **Topik Trending** - Topik trending terkini terkait kata kunci Anda

### 📝 Struktur Konten yang Dihasilkan

Setiap artikel yang dihasilkan AI mencakup:

1. **Informasi Meta:**
   - Judul dioptimalkan SEO (55-60 karakter)
   - Meta description (150-160 karakter)
   - Slug URL-friendly
   - Daftar kata kunci target

2. **Konten Artikel:**
   - Pendahuluan yang menarik
   - Isi terstruktur dengan heading
   - Poin-poin pembahasan kunci
   - Istilah kontekstual dan LSI keywords
   - Kesimpulan yang kuat
   - Bagian FAQ dengan pasangan T&J

3. **Peningkatan SEO:**
   - Saran tautan internal
   - Saran bacaan inline
   - Deskripsi featured image
   - Article schema (JSON-LD)
   - FAQ schema (jika FAQ disertakan)

4. **Analitik:**
   - Rincian skor SEO
   - Saran perbaikan SEO
   - Analisis keterbacaan

## Pengaturan

### 1. Dapatkan API Key Google Gemini

1. Kunjungi [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Login dengan akun Google Anda
3. Klik "Create API Key"
4. Salin API key Anda (dimulai dengan "AIza...")

### 2. Konfigurasi API Key di SOFIR

1. Buka **WordPress Admin → SOFIR → tab SEO**
2. Temukan bagian "AI Article Generator" di bagian atas
3. Tempel Google Gemini API key Anda di field
4. Klik "Save API Key"

Generator Artikel AI sekarang siap digunakan!

## Cara Penggunaan

### Membuat Artikel

1. **Buka Tab SEO:**
   - Buka **SOFIR → SEO** di WordPress admin

2. **Konfigurasi Pengaturan Artikel:**
   - Masukkan judul artikel atau topik
   - Tambahkan kata kunci target
   - Pilih tujuan artikel
   - Pilih tone
   - Set jumlah kata
   - Pilih sudut pandang
   - Pilih level keterbacaan
   - Sesuaikan slider kreativitas
   - Centang opsi FAQ/TOC

3. **Generate:**
   - Klik tombol "Generate Article"
   - Tunggu 30-60 detik untuk generasi AI
   - Review konten yang dihasilkan

4. **Review Hasil:**
   - Cek skor SEO dan saran
   - Review kualitas konten
   - Verifikasi penempatan kata kunci
   - Cek semua bagian

5. **Simpan atau Publikasikan:**
   - Klik "Save as Draft" untuk simpan sebagai draft
   - Klik "Publish" untuk publikasikan langsung
   - Anda akan diarahkan ke editor posting

### Menggunakan Riset Kata Kunci

1. **Pindah ke Tab Keyword Research:**
   - Klik tab "Keyword Research" di AI Generator

2. **Masukkan Kata Kunci Seed:**
   - Ketik kata kunci utama Anda
   - Klik "Research Keywords"

3. **Review Hasil:**
   - Variasi kata kunci dengan kesulitan dan volume
   - Long-tail keywords untuk targeting spesifik
   - Kata kunci terkait dan LSI
   - Kata kunci berbasis pertanyaan
   - Topik trending

4. **Gunakan Insight:**
   - Gunakan temuan untuk meningkatkan targeting artikel
   - Pilih kata kunci terbaik untuk konten Anda
   - Identifikasi peluang konten

1. **Spesifik dengan Judul:**
   - Gunakan judul yang jelas dan deskriptif

2. **Pilih Tone yang Tepat:**
   - Profesional untuk konten bisnis

5. **Optimalkan Lebih Lanjut:**

   - Sertakan gambar dengan alt text
   - Format untuk keterbacaan

## API Endpoints

Untuk developer yang ingin integrasi secara programatis:

### Generate Article

```
POST /wp-json/sofir/v1/seo-ai/generate
```

**Parameter:**
- `title` (string, wajib) - Judul artikel
- `keyword` (string, wajib) - Kata kunci target
- `purpose` (string) - Tujuan artikel
- `tone` (string) - Tone penulisan
- `word_count` (int) - Jumlah kata
- `pov` (string) - Sudut pandang
- `readability` (string) - Level keterbacaan
- `creativity` (float) - Level kreativitas (0-1)
- `include_faq` (bool) - Sertakan bagian FAQ
- `include_toc` (bool) - Sertakan daftar isi

**Response:** Objek artikel lengkap dengan semua konten yang dihasilkan

### Research Keywords

```
POST /wp-json/sofir/v1/seo-ai/keywords
```

**Parameter:**
- `keyword` (string, wajib) - Kata kunci seed

**Response:** Data riset kata kunci dengan variasi dan saran

## Troubleshooting

### Masalah API Key

**Masalah:** Error "API key is not configured"
- **Solusi:** Verifikasi API key Anda tersimpan di SOFIR → SEO settings
- **Cek:** API key dimulai dengan "AIza..."

**Masalah:** Error "API request failed"
- **Solusi:** Cek apakah API key Anda valid
- **Aksi:** Generate key baru dari Google AI Studio

### Masalah Generasi

**Masalah:** Generasi terlalu lama
- **Alasan:** Request kompleks atau jumlah kata tinggi
- **Tip:** Coba jumlah kata lebih pendek (800-1500 kata)

**Masalah:** Konten kosong atau tidak lengkap
- **Solusi:** Coba generate ulang dengan pengaturan berbeda
- **Cek:** Limit quota API key

**Masalah:** Konten tidak dioptimalkan SEO
- **Solusi:** Lebih spesifik dengan kata kunci dan tujuan
- **Tip:** Gunakan tool keyword research terlebih dahulu
