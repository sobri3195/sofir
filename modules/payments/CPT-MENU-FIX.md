# Payment CPT Menu Fix v2.1

## 🐛 Problem

Products, Coupons, Subscriptions, dan Invoices tidak tampil di menu setelah dibuat post baru.

**Root Cause**: CPT didaftarkan dengan `'show_in_menu' => false` tetapi submenu manual menggunakan `edit.php?post_type=sofir_product` tidak kompatibel. WordPress tidak bisa menampilkan halaman list post dengan benar karena CPT tidak "attached" ke menu parent.

## ✅ Solution

### 1. Proper CPT Registration

Changed `'show_in_menu' => false` to `'show_in_menu' => 'sofir-payments'` untuk semua 4 CPT:

```php
\register_post_type(
    'sofir_product',
    [
        'label' => \__( 'Products', 'sofir' ),
        'labels' => [
            'name' => \__( 'Products', 'sofir' ),
            'singular_name' => \__( 'Product', 'sofir' ),
            'add_new' => \__( 'Add New', 'sofir' ),
            'add_new_item' => \__( 'Add New Product', 'sofir' ),
            'edit_item' => \__( 'Edit Product', 'sofir' ),
            // ... full labels array
        ],
        'public' => true,
        'show_ui' => true,
        'show_in_menu' => 'sofir-payments',  // ← KEY FIX
        'supports' => [ 'title', 'editor', 'thumbnail' ],
        'capability_type' => 'post',
        'has_archive' => true,
        'menu_position' => 4,
    ]
);
```

**Benefits**:
- WordPress otomatis register submenu untuk CPT
- Menu link berfungsi dengan benar
- Halaman Add New, Edit, List posts semua tampil
- Konsisten dengan WordPress best practices

### 2. Removed Manual Submenu

Deleted manual `add_submenu_page()` calls untuk Products, Coupons, Subscriptions, Invoices:

```php
// ❌ BEFORE - Manual submenu (tidak perlu)
\add_submenu_page(
    'sofir-payments',
    \__( 'Products', 'sofir' ),
    \__( 'Products', 'sofir' ),
    'manage_options',
    'edit.php?post_type=sofir_product'
);

// ✅ AFTER - Auto-generated oleh WordPress
// (tidak ada code, WordPress otomatis menambahkan)
```

**Benefits**:
- Menghindari duplikasi menu
- Menghindari menu conflict
- Lebih clean dan maintainable
- Urutan menu mengikuti `menu_position` di CPT registration

### 3. Auto-Flush Rewrite Rules

Tambahkan version-based rewrite rules flushing:

```php
public function boot(): void {
    \add_action( 'init', [ $this, 'register_payment_cpt' ] );
    \add_action( 'admin_init', [ $this, 'maybe_flush_rewrite_rules' ] );
    // ...
}

public function maybe_flush_rewrite_rules(): void {
    $version = \get_option( 'sofir_payment_cpt_version', '1.0.0' );
    $current_version = '1.0.1';

    if ( \version_compare( $version, $current_version, '<' ) ) {
        \flush_rewrite_rules();
        \update_option( 'sofir_payment_cpt_version', $current_version );
    }
}
```

**Benefits**:
- Auto-flush saat plugin update
- Tidak perlu manual flush di Settings → Permalinks
- Version-based jadi flush hanya run once per update
- Performance friendly
