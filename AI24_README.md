## 🔍 Key Research Findings

### What is AI24?
AI24 Assistant Integrator is a WordPress plugin that provides OpenAI Assistants API integration with:
- **Chatbot Widget** - On-page AI assistant
- **State Management** - Cross-tab chat synchronization
- **Performance** - 50% faster responses (optimized)
- **Customization** - Styling and behavior options
- **Extensibility** - Hooks and filters for integration

### Current SOFIR AI
The existing AI module (`/modules/ai/builder.php`):
- ✓ Local content analysis
- ✓ Keyword extraction
- ✓ Meta description generation
- ✓ SEO scoring
- ✗ No external AI service
- ✗ No LLM integration

### Integration Opportunity
Combining SOFIR's local AI with AI24's OpenAI integration creates:
- **Content Generation** - AI-powered article/description creation
- **Smart Suggestions** - Context-aware recommendations
- **SEO Optimization** - AI-enhanced SEO tools
- **Voxel Support** - Powerful features for Voxel CPTs
- **Chat Assistant** - Customer interaction automation

### Proposed Module Architecture
```
/modules/ai24-integrator/
├── manager.php              (Singleton, lifecycle)
├── bridge.php               (API communication)
├── class-ai24-config.php    (Settings management)
├── voxel-integration.php    (Voxel features)
├── rest-api.php             (REST endpoints)
├── admin-panel.php          (Admin UI)
└── [documentation & assets]
```

## 📝 Naming Conventions

### SOFIR Standards Followed
```php
// Namespace
namespace Sofir\Ai24Integrator;

// Classes (PascalCase)
class Manager
class Bridge
class Config
class Voxel_Integration
class REST_API
class Admin_Panel

// Options (sofir_ai24_* prefix)
sofir_ai24_enabled
sofir_ai24_api_key
sofir_ai24_voxel_enabled

// Hooks (sofir/ai24/* format)
sofir/ai24/connected
sofir/ai24/suggestion_generated
sofir/ai24/voxel_updated

// Files (kebab-case with sofir- prefix)
/modules/ai24-integrator/manager.php
/modules/ai24-integrator/bridge.php
```
