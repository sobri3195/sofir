# Template Mobile Elementor SOFIR

## Ringkasan

Koleksi lengkap 20 template Elementor yang dirancang khusus untuk mobile, terinspirasi dari sistem desain modern seperti **Arcade** dan **Swipe Pages**. Template ini menampilkan gradient yang berani, tipografi yang bersih, dan tata letak yang fokus pada konversi untuk perangkat mobile.

## Inspirasi Desain

### Gaya Arcade
- Antarmuka bersih dan minimalis
- Latar belakang gradient berani (ungu, biru, pink)
- Tipografi modern dengan font tebal
- Elemen interaktif dengan animasi halus
- Ruang putih yang luas
- Pendekatan mobile-first

### Gaya Swipe Pages
- Tata letak berbasis kartu
- Gradient berwarna berani
- Hierarki visual yang kuat
- Desain fokus konversi
- Transisi yang halus
- Teks yang besar dan mudah dibaca

## Panduan Penggunaan

### Pendekatan Mobile-First
1. **Optimalkan untuk Touch**: Target touch minimum 44px
2. **Teks Mudah Dibaca**: Teks body minimum 16px
3. **Spacing Luas**: Padding seksi 20-40px
4. **Tipografi Tebal**: Font weight 700-900
5. **Kontras Tinggi**: Teks gelap di terang, terang di gelap

### Performa
1. **Gradient Dioptimalkan**: CSS gradient (tanpa gambar)
2. **Aset Minimal**: Berbasis teks dan ikon
3. **Lazy Loading**: Muat gambar sesuai kebutuhan
4. **Ukuran File Kecil**: Template berbasis JSON

### Aksesibilitas
1. **Kontras Warna**: Sesuai WCAG AA
2. **Ukuran Font**: Teks besar dan mudah dibaca
3. **Target Touch**: Minimum 44px
4. **Hierarki Jelas**: Heading tebal, seksi jelas

## Instruksi Import

1. Buka editor Elementor
2. Klik tombol "SOFIR Templates" (ikon folder)
3. Telusuri berdasarkan kategori: Slider, Card, Page, Single, Archive
4. Cari berdasarkan tag: mobile, arcade, gradient, swipe
5. Preview template dengan modal layar penuh
6. Klik "Insert" untuk menambahkan ke halaman
